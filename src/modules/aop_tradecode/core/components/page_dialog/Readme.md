# 使用规则

## 传入变量

- dialogVisiable:           对话框显示与否
- dialogWidth:              对话框宽度
- dialogTitle:              对话框标题
- modalAppendToBody         遮罩层是否插入至 body 元素上
- apTobody                   Dialog 自身是否插入至 body 元素上,嵌套的 Dialog 必须指定该属性并赋值为 true
